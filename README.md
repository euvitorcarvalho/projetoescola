<h1>PROJETO ESCOLA</h1>

<h2>Desenvolver um programa em C que controle o funcionamento de uma Escola.</h2>

<h3>Funcionalidades solicitadas:</h3>

<ul>
  <li><strong>Cadastro de Alunos</strong> (Matrícula, Nome, Sexo, Data Nascimento, CPF) ✅</li>
  <li><strong>Cadastro de Professores</strong> (Matrícula, Nome, Sexo, Data Nascimento, CPF) ✅</li>
  
  <li><strong>Cadastro de Disciplinas</strong> (Nome, Código, Semestre, Professor) 🔴
    <ul>
      <li>Inserir/Excluir aluno de uma disciplina 🔴</li>
    </ul>
  </li>

  <li><strong>Relatórios</strong>
    <ul>
      <li>Listar Alunos ✅</li>
      <li>Listar Professores ✅</li>
      <li>Listar Disciplinas (dados da disciplina sem os alunos) 🔴</li>
      <li>Listar uma disciplina (dados da disciplina e os alunos matriculados) 🔴</li>
      <li>Listar Alunos por sexo (Masculino/Feminino) ✅</li>
      <li>Listar Alunos ordenados por Nome ✅</li>
      <li>Listar Alunos ordenados por data de nascimento ✅</li>
      <li>Listar Professores por sexo (Masculino/Feminino) ✅</li>
      <li>Listar Professores ordenados por Nome ✅</li>
      <li>Listar Professores ordenados por data de nascimento ✅</li>
      <li>Aniversariantes do mês 🔴</li>
      <li>Lista de pessoas (professor/aluno) a partir de uma string de busca. 🟡
        <p><em>O usuário informa no mínimo três letras e deve ser listado todas as pessoas que contêm essas três letras no nome.</em></p>
      </li>
      <li>Lista de alunos matriculados em menos de 3 disciplinas 🔴</li>
      <li>Lista de Disciplinas, com nome do professor, que extrapolam 40 vagas. 🔴</li>
    </ul>
  </li>
</ul>
